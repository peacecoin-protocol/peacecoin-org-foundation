_How to use PEACE COIN with Slack_

The following features of PEACE COIN can be used by Slack command operation.

1. Log into/out of your PEACE COIN Web Wallet account
2. Send messages with Tokens (Coins)
3. Check the balance of PEACE COIN Wallet
4. Check how to use commands on Slack
5. Set up to link PEACE COIN with emoji on slack (workspace administrators only)

List of Slack commands

### /arigato_login
You can log into your PEACE COIN Wallet to send PEACE COIN Token on Slack. Enter the email address and password you registered to PEACE COIN Wallet app to log in. Once logged in, you can use the following commands.

### /arigato_logout
You can log out of your PEACE COIN Wallet. If you want to use PEACE COIN on Slack again, enter the command /arigato_login

### /arigato
Send Tokens (Coins) on Slack. The amount to be sent should be greater than 0, should be entered in one-byte characters and the message should be 500 characters or less.

### /arigato_wallet
Displays the balance of the community tokens you hold.

### /arigato_howto
Displays how to use each command available on Slack.

### /arigato_setup (for administrators)
Administrators can set the amount of tokens to be sent by each emoji in your Slack workspace.

※If PEACE COIN bot is not installed in your Slack workspace, you need to “3. Install PEACE COIN Bot in Slack Workspace”. Install PEACE COIN bot on each channel where you want to send and receive PEACE COIN.

※To register PEACE COIN Wallet app, click <a href="https://wallet.peace-coin.com/" target="_blank" rel="noopener">here</a>.

※If you have forgotten your login password, you can reset it here.


## 1. Log into PEACE COIN Wallet on Slack
![How to use PEACE COIN with Slack](/assets/images/content/howto-peace-coin-slack/2.png)
_How to use PEACE COIN with Slack_

①Enter the command“/arigato_login”in the message field and tap “Send now” button. A pop-up window will appear, then tap “Login.”

②Enter youremail address and password registered to PEACE COIN Wallet, and tap “Login”.

![How to use PEACE COIN with Slack](/assets/images/content/howto-peace-coin-slack/3.png)
_How to use PEACE COIN with Slack_

③When another window opens, tap “Connection.”Now you logged into PEACE COIN Wallet and linked to Slack workspace even if you don’t go back to Slack automatically from “Back to Slack.” 

④The message “Successful connection” will be displayed.

## 2. Send PEACE COIN Token by “arigato” Command

![How to use PEACE COIN with Slack](/assets/images/content/howto-peace-coin-slack/4.png)
_How to use PEACE COIN with Slack_

⑤Enter the command “/arigato”in the message field and  tap “Send now” button. A pop-up window will appear.

![How to use PEACE COIN with Slack](/assets/images/content/howto-peace-coin-slack/5.png)
_How to use PEACE COIN with Slack_

⑥After PEACE COIN Wallet is launched, enter the“Destination account”,“Amount to send”, and“Message.”

※If the receiver is not logged into PEACE COIN Wallet on Slack, an error message will be displayed.

- You can also send PEACE COIN Token by directly entering the “/arigato” command, “Send to“, “Amount“, and “Message” into the message field.
※You need to enter a half-width space between each item.

![How to use PEACE COIN with Slack](/assets/images/content/howto-peace-coin-slack/6.png)
_How to use PEACE COIN with Slack_

⑦You can also send PEACE COIN Token by entering an EMOJI (pictogram) in the message field.

※PEACE COIN Token will be sent to the member named by @ mark.

## 4. Link PEACE COIN Token with EMOJI in Slack Workspace

![How to use PEACE COIN with Slack](/assets/images/content/howto-peace-coin-slack/9.png)
_How to use PEACE COIN with Slack_

❺Select the community token you hold in the“Community Tokens”section.

❻In“Emoji Settings,”set the “Emoji (pictogram)”and “Amount”individually. If you enter “other” for emoji section, a uniform amount will be sent for all pictograms.

(e.g.):peacecoin: _100
* “_” means a half-width space between the emoji and the amount.

When you have completed the settings, click the “Settings”button.
